# Fonti delle API: cosa è verificato e cosa no

Verificato il 2026-09-30 con il server MCP SAP Docs (SAP Help Portal) e la ricerca web. Prima di usare un'API di questa lista in uno sviluppo, rileggi la pagina: SAP le aggiorna.

## Verificato sulla documentazione SAP

| Cosa | Dettaglio verificato | Fonte |
|---|---|---|
| Avvio dei job di Identity Provisioning | `POST https://<ias-tenant-host>/ips/service/publicapi/v1/startJob/{SourceSystemId}/jobs/{JobType}`, con `JobType` = `READ` o `RESYNC`; `SourceSystemId` è la fine dell'URL del sistema sorgente nella console. Solo per tenant IPS su SAP Cloud Identity infrastructure. | [Run Provisioning Jobs via API](https://help.sap.com/docs/IDENTITY_AUTHENTICATION/6d6d63354d1242d185ab4830fc04feb1/9574b40cc92b40b69857be348aa15b0c.html) |
| Utente tecnico del job | Amministratore di tipo *System* con il ruolo *Access Identity Provisioning Tenant Admin API*; secret (client ID e client secret) o certificato. | [Add Administrators](https://help.sap.com/docs/IDENTITY_AUTHENTICATION/6d6d63354d1242d185ab4830fc04feb1/bbbdbdd3899942ce874f3aae9ba9e21d.html) |
| Autenticazione del job | `POST` con *Basic Auth*: client ID come utente, client secret come password. | [KBA: How to run provisioning jobs via API](https://help.sap.com/docs/SUPPORT_CONTENT/btpcfsec/3361873344.html) |
| Simulate | Il job *Simulate* parte dalla console (*Jobs > Run Now*), non dall'API, che accetta solo READ e RESYNC. | [Start and Stop Provisioning Jobs](https://help.sap.com/docs/IDENTITY_AUTHENTICATION/6d6d63354d1242d185ab4830fc04feb1/531a2615b2d04eb8ba46a638b6d81cdc.html), pagina del job via API |
| Identity Directory SCIM | `/scim/Users`, `/scim/Groups` sostituiscono le API deprecate `/service/scim/Users`, `/service/scim/Groups`; gli id sono UUID; l'assegnazione di un utente a un gruppo si fa sull'endpoint dei gruppi. | [Migrating Deprecated Identity Authentication API to Identity Directory API](https://help.sap.com/docs/IDENTITY_AUTHENTICATION/6d6d63354d1242d185ab4830fc04feb1/106dbe0c3fa9473396eb204acedebe5f.html) |
| Diritti per Identity Directory | Amministratore di tipo *System* con *Manage Users*; per i gruppi anche *Manage Groups*. | [Identity Directory API](https://help.sap.com/docs/IDENTITY_AUTHENTICATION/6d6d63354d1242d185ab4830fc04feb1/5be569254a3246b18348e35ffc6b11a7.html), [Identity Authentication come sorgente](https://help.sap.com/docs/IDENTITY_AUTHENTICATION/6d6d63354d1242d185ab4830fc04feb1/e4e25f1fae094c2a89ad62159e1cd230.html) |
| Token e payload SCIM | Token OAuth2 client credentials su `https://<ias-host>/oauth2/token` (client ID e secret nel corpo); `Content-Type: application/scim+json`; gruppo con gli schemi `urn:ietf:params:scim:schemas:core:2.0:Group` e `urn:sap:cloud:scim:schemas:extension:custom:2.0:Group`; membri aggiunti con `PATCH /scim/Groups/{id}`, schema `urn:ietf:params:scim:api:messages:2.0:PatchOp`, `{"op":"add","path":"members","value":[{"value":"<id>","type":"User"}]}`. | Codice del provider Terraform ufficiale SAP `SAP/terraform-provider-sap-cloud-identity-services` al commit `bd01208` (`sci/provider/provider.go`, `internal/cli/groups.go`, `internal/cli/client.go`) |
| API SCIM versione 1 | L'API SCIM versione 1 di Identity Authentication viene dismessa il 30 novembre 2026: il sistema sorgente IAS deve avere `ias.api.version=2`. | Pagina *Identity Authentication* come sorgente (sopra) |
| Real-time provisioning | URL `https://<ias-tenant-host>/ipsproxy/service/api/v1/systems/<system-id>/entities/user` (e `.../entities/group` per i gruppi, POST e DELETE), utente tecnico con *Access Real-Time Provisioning API*. Si configura nella console, tile *Real-Time Provisioning*. | [Configure Identity Authentication for Real-Time Provisioning](https://help.sap.com/docs/IDENTITY_AUTHENTICATION/6d6d63354d1242d185ab4830fc04feb1/334964514e8b48cb88c8ed07f5ee6a14.html) |
| Target SAP BTP XS Advanced UAA | Proprietà `Type`, `URL` (`https://api.authentication.<region>.hana.ondemand.com`), `ProxyType`, `Authentication=BasicAuthentication`, `OAuth2TokenServiceURL`, `User`, `Password`, `xsuaa.origin`; un target per global account, directory o subaccount; i gruppi sono le role collection. | [SAP BTP XS Advanced UAA (Cloud Foundry) come target](https://help.sap.com/docs/IDENTITY_AUTHENTICATION/6d6d63354d1242d185ab4830fc04feb1/ecddce6d325e41b49089d4f3a2ce9a18.html) |
| Target SAP S/4HANA Cloud Public Edition | Versione 1 (`SAP_COM_0193`, SOAP Business User, gruppi = business role) o 3 (`SAP_COM_0465`, SCIM, gruppi utente e role); i business role devono esistere; proprietà `s4hana.cloud.*`. | [SAP S/4HANA Cloud Public Edition come target](https://help.sap.com/docs/IDENTITY_AUTHENTICATION/6d6d63354d1242d185ab4830fc04feb1/40940b8223334b528e4899b92d42ce96.html) |

## Non verificato: resta un passo manuale o da controllare

| Cosa | Perché | Cosa fai |
|---|---|---|
| Creazione e modifica di sistemi sorgente e target, proprietà e trasformazioni | La documentazione SAP non pubblica un'API per configurarli; un blog della community cita endpoint `uiapi` usabili solo in sessione browser. | Prepari la configurazione esatta (proprietà e JSON delle trasformazioni) e la consegni all'amministratore di IPS, che la inserisce nella console. |
| Esito e log dei job via API | Un blog della community (SAP, 2025) cita `GET /ips/service/publicapi/v1/jobLogs/{jobId}`; nella documentazione SAP non l'ho trovato, e l'id del job va copiato dalla console. | L'esito si legge in *Identity Provisioning > Provisioning Logs*. |
| Pianificazione dei job via API | Nessuna API documentata. | La pianificazione (*Schedule*) la imposta l'amministratore nella console. |
| Payload dei push in tempo reale dei gruppi | La pagina SAP indica URL e metodi, non il formato del corpo. | Non automatizzato: se serve, l'amministratore lo configura seguendo la pagina SAP e la specifica `IPS_Proxy` sul SAP Business Accelerator Hub. |
| Autenticazione con certificato sull'API dei job | La pagina del job mostra solo l'utente tecnico; il certificato è documentato per gli amministratori di tipo System in generale. | Lo script lo supporta (`IPS_CERT_P12`) solo se l'amministratore conferma che il tenant lo accetta; il default è Basic. |
| Specifiche OpenAPI sul SAP Business Accelerator Hub (`IPS_Proxy`, `IdDS_SCIM`) | Il download richiede il login; non le ho lette. | In caso di dubbio su un campo, apri la specifica con il tuo login e confrontala con i payload di `seed.example.json`. |
