# Common UI5 Control Types

## Buttons

| Control Type | Usage |
| --- | --- |
| `sap.m.Button` | Standard button |
| `sap.m.OverflowToolbarButton` | Toolbar overflow button |
| `sap.m.SegmentedButton` | Segmented toggle button |
| `sap.m.MenuButton` | Button with dropdown menu |

## Inputs

| Control Type | Usage |
| --- | --- |
| `sap.m.Input` | Basic text input |
| `sap.m.SearchField` | Search input with icon |
| `sap.m.TextArea` | Multi-line text |
| `sap.m.DatePicker` | Date selection |
| `sap.m.TimePicker` | Time selection |
| `sap.m.DateTimePicker` | Combined date + time |
| `sap.m.StepInput` | Numeric stepper |
| `sap.ui.comp.smartfield.SmartField` | Auto-generated field from OData |
| `sap.ui.comp.smartfilterbar.SmartFilterBar` | Filter bar from annotations |

## Selection

| Control Type | Usage |
| --- | --- |
| `sap.m.Select` | Dropdown select |
| `sap.m.ComboBox` | Editable dropdown |
| `sap.m.MultiComboBox` | Multi-select dropdown |
| `sap.m.RadioButton` | Radio option |
| `sap.m.CheckBox` | Checkbox toggle |
| `sap.m.Switch` | On/off toggle |

## Display

| Control Type | Usage |
| --- | --- |
| `sap.m.Text` | Static text |
| `sap.m.Label` | Field label |
| `sap.m.Title` | Section/page title |
| `sap.m.ObjectStatus` | Status with icon/color |
| `sap.m.ObjectNumber` | Formatted number |
| `sap.m.ObjectIdentifier` | Title + description pair |
| `sap.m.Link` | Clickable link |
| `sap.m.MessageStrip` | Inline message banner |

## Containers

| Control Type | Usage |
| --- | --- |
| `sap.m.Table` | Responsive table |
| `sap.ui.table.Table` | Grid table (large datasets) |
| `sap.ui.comp.smarttable.SmartTable` | Auto-generated table |
| `sap.m.List` | Vertical list |
| `sap.m.Dialog` | Modal dialog |
| `sap.m.Popover` | Popover overlay |
| `sap.m.Panel` | Collapsible panel |
| `sap.uxap.ObjectPageLayout` | Object page container |
| `sap.f.DynamicPage` | Dynamic page with header |
| `sap.m.IconTabBar` | Tab container |
| `sap.m.IconTabFilter` | Individual tab |
